      Query tables

      Tables inserted with “Refreshable table” remember their query. Refresh re-runs it against current data.

        Help

        Queries run in SQLite against the workbook data each time you run them.

        Excel tableSELECT * FROM Sales
        Named rangeSELECT * FROM MyRange
        Whole sheetSELECT * FROM [Sheet 1]
        Any rangeSELECT * FROM [Sheet1!A1:D200]
        Spaces in names[Unit Price] or "Unit Price"
        • The first row of a range or sheet is used as column headers.
        • Date cells become ISO text (2024-01-31), so date(), strftime() and text comparisons work.
        • Joins, GROUP BY, CTEs (WITH), window functions and multiple statements are supported. The last result set is shown.
        • Select part of the editor text to run just that part.
        • TRUE/FALSE become 1/0. Empty cells become NULL.
