Workbook objects
    Help

    Queries run in SQLite against the workbook data each time you run them.

    Excel tableSELECT * FROM Sales
    Named rangeSELECT * FROM MyRange
    Whole sheetSELECT * FROM [Sheet 1]
    Any rangeSELECT * FROM [Sheet1!A1:D200]
    No header rowSELECT A, C FROM [Sheet1!A1:D200 noheader]
    Spaces in names[Unit Price] or "Unit Price"
    • The first row of a range, sheet or named range is used as column headers. Add noheader inside the brackets when there is no header row: every row is then data and columns are named by their sheet letters.
    • Date cells become ISO text (2024-01-31), so date(), strftime() and text comparisons work.
    • Joins, GROUP BY, CTEs (WITH), window functions and multiple statements are supported. The last result set is shown.
    • SQL = is case-sensitive. Add COLLATE NOCASE to match like XLOOKUP.
    • Select part of the editor text to run just that part.
    • Turn on Pick from sheet, then select cells: the pane shows the matching table, named range, sheet or range reference and inserts it at the cursor. It also offers the selected column names (for SELECT) and a single cell's value (for WHERE).

    Combine tables without writing SQL. The builder writes the query; you can run it or open it in the editor.
